# 五目定石帳（gomoku-joseki）

連珠（黒に禁手あり）の26珠型の定石を、**閲覧 → 練習 → 復習** で覚えるPWA。ME IS ME。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173/gomoku-joseki/
npm test         # ルール・正規化・定石データの検証
npm run build
```

## 構成

| パス | 内容 |
|---|---|
| `src/lib/rules.ts` | 15路盤、着手、五連、禁手（三三・四四・長連） |
| `src/lib/symmetry.ts` | 8対称の変換と局面IDの正規化 |
| `src/lib/openings.ts` | 26珠型（3手目まで） |
| `src/lib/book.ts` | 定石グラフ（局面ノード＋手エッジ）の操作 |
| `src/lib/validate.ts` | 定石データの自動チェック（禁手登録・対称重複・next不一致） |
| `src/lib/records.ts` | 学習記録と間隔反復 |
| `src/data/book.json` | アプリ同梱の定石データ |
| `src/screens/` | ホーム／珠型一覧／閲覧（編集）／練習／復習／設定 |

## 定石データの作り方

1. 珠型一覧 → 珠型 → 閲覧 → 右上「編集」
2. 盤をタップ → もう一度タップで定石手を登録（最初の手が主変化）
3. 手ごとのコメント、局面の評価（黒有利／白有利／互角）とメモを入力
4. 設定 →「書き出す」で `book.json` をダウンロード
5. それを `src/data/book.json` に置き換えてコミット（`npm test` が同梱データを検証）

コメントは定石書・サイトの文章を写さず、自分の言葉で書く。

## 局面ID

黒石・白石の位置を8通りに変換し、辞書順最小の表現を正規形とする（ハッシュせず文字列そのものをIDに使用）。
手の座標（`to`）は正規形の座標系で保存し、表示時に逆変換する。手順前後で合流した局面はノード1つ。

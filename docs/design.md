# 五目定石帳（gomoku-joseki）設計書

## 0. 前提と方針
- 将棋版「定跡帳」・リバーシ版「定石帳」と同じ考え方・同じ見た目（暗い背景の「静かな鍛錬」テーマ）・同じ操作感で作る。コードはリバーシ版（`eeeme/reversi-joseki`）をもとに、盤とルールだけを差し替えた。
- 無料・広告なし。応援（1回きり3種と毎月）だけを持つ。データはすべて端末内に保存し、外には送らない。
- 将棋版・リバーシ版で外したもの（解析エンジン、評価値、局面の共有、問題集）は入れない。
- ルールは連珠（黒に禁手あり）。開局規定（交替打ち・5手目の提示など）は扱わず、1手目は天元（H8）固定。

## 3. ルールと盤（`src/gomoku/core.ts`）

- 225点の配列。0＝空、1＝黒、2＝白。点の番号は `a1=0 … o15=224`（列 a〜o、行 1〜15。画面では15行目が上）。
- 局面文字列は225文字（`-`／`X`／`O`）＋手番1文字。
- 1手目は天元（H8）。五連で終局（黒はちょうど五、白は六以上も可）。盤が埋まれば引き分け。
- 黒の禁手：三三・四四（一直線の四四も含む）・長連。三は「禁手でない点に打って達四にできる」本物の三だけを数える（再帰判定）。五連は禁手より優先。
- 対称変換は8通り（すべて天元を動かさない）。合流・局面検索は8対称のうち最小の文字列で比べる。

## 4. 向きの正規化（`src/gomoku/notation.ts`）
- 天元から始まる手順は、3手目までが26珠型なら珠型の標準の向きに、そうでなければ「2手目から順に、なるべく上・右」になる向きに盤ごと回して記録する。
- 直接打ちは2手目が H9、間接打ちは2手目が I9 になる。
- 取り込んだ棋譜も、盤で打った2・3手目も同じ規則でそろえる。向き違いの同じ手順は1本にまとまる。

## 5. 棋譜（`src/gomoku/kifu.ts`）

| 形式 | 例・内容 |
|---|---|
| 棋譜文字列 | `h8i9j10…`（大文字・空白・改行・手数の番号まじりでもよい） |
| 複数行 | 1行1手順。分岐付きの1冊にまとめる |
| 盤面図 | 15行の `X / O / -`（上が15行目）＋手番 |

- 書き出しは「本線」と「全変化を1行ずつ」をコピー。
- 実戦照合：自分の対局を貼ると、何手目で定石を外れたか・定石では何を打つかを表示。
- 五連まで打った棋譜は勝敗（黒勝ち／白勝ち）を対局情報に入れる。

## 6. 珠型（`src/gomoku/openings.ts`）
- 26珠型（直接打ち13・間接打ち13）の名前と3手目までの手順の表。3手目の位置は国際連珠連盟（RIF）の標準の番号付けに合わせた。
- その局面が珠型ならツリーの枠と閲覧画面に名前を出し、先へ進んでも名前を引き継ぐ。
- サンプル本は「26珠型（3手目まで）」1冊。4手目より先の定石は自分で調べて足していく（定石書・サイトの文章はメモに写さない）。

## 7. 盤（`src/ui/Board.tsx`）
- 暗い盤に細い線、交点に黒石・白石。星は5つ。直前の手は金の印（手数表示中は金の数字）。
- 石の上に手数を出す（本の開始局面からの手数）。
- 黒番のときは禁手点に×を常に表示（石を隠す練習中と盤面編集では出さない）。
- 15路はスマホだと1路が狭いので、手を打つときは「タップで仮置き → 同じ点をもう一度タップで確定」。
- 閲覧中（編集オフ）は、盤の右半分のタップで本線を1手進め、左半分のタップで1手戻る。

## 8. データ構造
リバーシ版と同じ（`Book` / `BookNode` / `Folder`）。`rootPos` は226文字の局面。IndexedDB のデータベース名は `gomoku-joseki`。
